# BZ_study — помощь студентам и репетитор по Python

Лендинг для студентов: тесты, лабораторные, проекты по программированию, Яндекс Практикум,
подготовка к предметам и пересдачам, репетиторство по Python, Адомо / Дата-аналитике
и программированию в целом.

**Сайт:** https://bogdanzhf.github.io/BZ_study/

**Связь:** [Telegram @Bogdanzhd](https://t.me/Bogdanzhd) · [канал @Back_Python](https://t.me/Back_Python)

## Структура

```
index.html   разметка и тексты
base.css     дизайн: хром, отражения, анимации, адаптив
theme.css    тема BZ_study: лайм + фиолет, стикер, подзаголовок
script.js    терминал, 3D-наклон, счётчики, появление при скролле
```

Чистые HTML / CSS / JavaScript без сборки. Адаптив: телефоны от 320px, планшеты, десктоп.

После правок CSS/JS увеличьте `?v=N` в ссылках на файлы в `index.html` — так посетители сразу получат свежую версию.

## Локальный запуск

```bash
python -m http.server 5173
```

## Публикация

Каждый пуш в `main` публикует сайт на GitHub Pages через `.github/workflows/pages.yml`.
